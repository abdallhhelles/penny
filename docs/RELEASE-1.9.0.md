# Penny 1.9.0

- **Your data is now encrypted.** Everything Penny saves, including every backup, is encrypted with AES-256 and locked to your Windows account. Nothing to set up.
- **Passcode = second lock.** Set a passcode and it also encrypts your data. You get a one-time recovery key in case you forget it or move to a new PC.
- **A guided tour for new users** that points at the real buttons, one by one. Replay it any time from Settings or Ctrl K.
- **Updates from GitHub with live progress.** Penny checks for new versions, shows download progress, verifies the signature, and tells you what's new before you restart.
- **Financial Health Report for every country.** Fully translated (English, Spanish, Arabic), international sources, country-specific rules marked, plus a plain-language glossary.
- **Save your report as a PDF** with one click.
- **Fresher look:** softer cards, clearer focus rings, an accent marker on the current page, and a tidier dashboard.
- Fixes: the welcome illustration logo, the "Copy" support button label, and the avatar picker layout.
